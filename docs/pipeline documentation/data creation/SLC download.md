# SLC Download

This document covers the MERIA Sentinel-1 SLC matching and download workflow used under `Data_Creation`.

## Files

- Source observations: `Data_Creation/MERIA_IDS_OF_INTERESTS.docx`
- Generated South Africa match table: `Data_Creation/meria_sa_plastic_s1_slc/MERIA_SA_plastic_nearest_S1_SLC_before_after.csv`
- Generated South Africa Word table: `Data_Creation/meria_sa_plastic_s1_slc/MERIA_SA_plastic_nearest_S1_SLC_before_after.docx`
- Generated point layers: `Data_Creation/meria_sa_plastic_s1_slc/MERIA_SA_plastic_points.csv`, `.shp`, and `.gpkg`
- Raw SLC downloads and manifests: `Data_Creation/meria_sa_plastic_s1_slc/processed_slc/`

## Match Table Generation

The South Africa match table is generated by:

```bash
python3 Data_Creation/build_meria_sa_s1_slc_matches.py
```

The script has the MERIA South Africa observations from `MERIA_IDS_OF_INTERESTS.docx` encoded as `OBSERVATIONS`. For each observation it:

1. Parses each latitude/longitude point.
2. Builds a padded WGS84 bounding box around the points.
3. Queries Copernicus Data Space OData products from `https://catalogue.dataspace.copernicus.eu/odata/v1/Products`.
4. Filters to `Collection/Name eq 'SENTINEL-1'`, AOI intersection, `contains(Name,'_SLC_')`, and the relevant time window.
5. Selects the nearest SLC before the Planet date start and the nearest SLC after the next midnight.
6. Writes the CSV, DOCX table, point CSV, shapefile, and GeoPackage.

The generated CSV includes both `points` and `point_coordinates`. `points` is the count; `point_coordinates` preserves the actual coordinate list from the source table.

## MERIA SA Download Command

Use `Data_Creation/process_meria_sa_slc_targets.py` with `--download-only` to fetch raw ASF SLC zip files without running SNAP:

```bash
python3 Data_Creation/process_meria_sa_slc_targets.py \
  --target MERIA_SA_004:before \
  --target MERIA_SA_004:after \
  --target MERIA_SA_005:before \
  --target MERIA_SA_005:after \
  --target MERIA_SA_006:before \
  --download-only \
  --keep-zip \
  --verbose
```

`MERIA_SA_006:after` uses the same SLC granule as `MERIA_SA_005:after`:

```text
S1A_IW_SLC__1SDV_20240615T165336_20240615T165404_054336_069C38_DBE9
```

If you need a separate `MERIA_SA_006:after` manifest and target folder, add:

```bash
--target MERIA_SA_006:after
```

The script builds ASF URLs from the Sentinel platform:

```text
S1A -> https://datapool.asf.alaska.edu/SLC/SA/{granule}.zip
S1B -> https://datapool.asf.alaska.edu/SLC/SB/{granule}.zip
S1C -> https://datapool.asf.alaska.edu/SLC/SC/{granule}.zip
```

Each target writes:

```text
Data_Creation/meria_sa_plastic_s1_slc/processed_slc/{OBS_ID}_{Area}/{before|after}_{YYYYMMDDTHHMMSS}/
  *_slc_manifest.json
  SLC/{granule}.zip
```

## Arguments

| Argument | Purpose |
|---|---|
| `--target OBS_ID:before` | Download the matched SLC before the observation date. Repeatable. |
| `--target OBS_ID:after` | Download the matched SLC after the observation date. Repeatable. |
| `--download-only` | Download/reuse the ASF zip, write a manifest, and stop before unzipping or SNAP. |
| `--keep-zip` | Keep the downloaded ASF zip. Use this for raw-data ingestion. |
| `--out-root` | Override the output root. Default is `Data_Creation/meria_sa_plastic_s1_slc/processed_slc`. |
| `--work-root` | Temporary work root for full processing. Not important for download-only runs. |
| `--pad-deg` | AOI padding in degrees around the MERIA points. Default is `0.04`. |
| `--verbose`, `-v` | Increase logging detail. |

## Mallorca UUID SLC

The source observation:

```text
cabcd011-9d82-4124-9f9c-120bdc406cf3
October 12, 2018 at 12:00 UTC
39.603N 3.468E
Patches visible along the Palma de Mallorca coast from 2018-10-11 onwards.
```

was resolved using the provided points:

```text
39.66174 N, 3.46868 E
39.57672 N, 3.42316 E
39.63309 N, 3.54552 E
39.62612 N, 3.37886 E
```

Using the same Copernicus OData SLC query logic, and treating "after the 11th" as after the end of `2018-10-11` (`2018-10-12 00:00 UTC`), the nearest SLC is:

```text
S1B_IW_SLC__1SDV_20181012T054431_20181012T054458_013115_0183B4_07F8.SAFE
Acquired: 2018-10-12 05:44:31 UTC
Delta from 2018-10-12 00:00 UTC: +5.74 h
ASF URL: https://datapool.asf.alaska.edu/SLC/SB/S1B_IW_SLC__1SDV_20181012T054431_20181012T054458_013115_0183B4_07F8.zip
```

Download it directly to `Data_Creation` with the same ASF helper used by the MERIA SA pipeline:

```bash
mkdir -p Data_Creation/meria_global_s1_slc/cabcd011-9d82-4124-9f9c-120bdc406cf3/SLC

python3 - <<'PY'
from pathlib import Path
import sys

sys.path.insert(0, "/mnt/d/Masters/Data_Creation")
sys.path.insert(0, "/mnt/d/Masters/Domain_SSL/Scripts/Preprocessing")

from process_meria_sa_slc_targets import stream_download_asf
from process_drift_slc import edl_auth

url = "https://datapool.asf.alaska.edu/SLC/SB/S1B_IW_SLC__1SDV_20181012T054431_20181012T054458_013115_0183B4_07F8.zip"
out = Path("Data_Creation/meria_global_s1_slc/cabcd011-9d82-4124-9f9c-120bdc406cf3/SLC/S1B_IW_SLC__1SDV_20181012T054431_20181012T054458_013115_0183B4_07F8.zip")

stream_download_asf(url, out, edl_auth())
PY
```

The downloaded file and small local manifest are:

```text

Data_Creation/meria_global_s1_slc/cabcd011-9d82-4124-9f9c-120bdc406cf3/slc_download_manifest.json
```

## Verification

List downloaded raw SLC zips:

```bash
find Data_Creation -path '*/SLC/*.zip' -printf '%p %s bytes\n' | sort
```

Check a MERIA SA download manifest:

```bash
python3 -m json.tool \
  Data_Creation/meria_sa_plastic_s1_slc/processed_slc/MERIA_SA_004_Durban/before_20220420T032018/MERIA_SA_004_Durban_before_20220420T032018_slc_manifest.json \
  | sed -n '1,80p'
```

Expected manifest status for a download-only run is:

```json
"status": "downloaded"
```
